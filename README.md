# Reseam skill

Use Reseam with your AI agent. The skill keeps a searchable local copy of the patch authoring, CLI, and HTTP API guides. It can also help you install the Reseam CLI or Java when a task needs them. [Reseam documentation](https://reseam.app/docs/)

## Install

The installer requires Node.js 22.20 or later with `npx`. The documentation helper requires Python 3.14 or later.

Run this command from the project where you want to use the skill.

```sh
npx skills add alexandreteles/reseam-skill --skill reseam --agent claude-code codex
```

To install for one agent, keep only its name after `--agent`. To use the skill across projects, add `--global`. [Skills CLI installation options](https://github.com/vercel-labs/skills/blob/main/docs/commands.md#options)

## Example request

Your AI agent will select the skill automatically when a task matches its description. Ask in plain language:

> How do I list the patches in a Reseam bundle?

Sadly, AI is here to stay; if I am going to use it, I would rather do so in a way that benefits the communities I am part of.

### Using AI to Contribute

I am completely fine with contributors using whatever tools fit their workflow. I only ask that you disclose when AI tools were used in a pull request, issue, or any other kind of contribution.

Contributions will still receive human review, and I am unlikely to adopt automated AI workflows for development or project operations. If you point an agent at this project, please also take the time to read the code, understand what it does, and write some comments yourself.
