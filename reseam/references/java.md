# Private Java setup

Read the Java requirements in the install or authoring guide for the selected release. A patch run needs a compatible runtime. Building the CLI or compiling a bundle needs a JDK.

1. Check the project Java version, `JAVA_HOME`, `java` on `PATH`, and any matching runtime already under `cache_root/java/`. Run the candidate's `bin/java -XshowSettings:properties -version` to check its version and architecture. For a JDK, also check `bin/javac -version`. On Windows use the corresponding `.exe` files.
2. If a suitable Java installation is missing, offer a private Eclipse Temurin archive. Show its type, version, platform, and destination. After approval, obtain release metadata from `https://api.adoptium.net/v3/assets/latest/<feature>/hotspot?os=<os>&architecture=<arch>&image_type=<jre-or-jdk>&vendor=eclipse`. Choose the OS, CPU, and Java feature required for this task. Use the matching `binary.package.link` and `binary.package.checksum`. Keep that exact archive for this installation. [Adoptium API](https://api.adoptium.net/) · [Archive installation](https://adoptium.net/installation/archives/)
3. Use a new staging directory inside `cache_root`. Verify the archive's SHA-256 checksum before extraction. Reject paths or links that resolve outside staging. For tar, open the archive with `tarfile.open` and use `archive.extractall(staging, filter="data")`. For ZIP, check member paths and extract ordinary files and directories. [Python archive filters](https://docs.python.org/3.14/library/tarfile.html#extraction-filters)
4. Find the Java home that contains `bin/java`. On macOS this is usually `Contents/Home` inside the bundle. Verify the staged Java, then move the complete installation into `java/temurin/<release>/<os>-<arch>/<jre-or-jdk>/`. Use real private directories and single-component release names. Reuse a compatible existing installation. Clean up only the staging directory created for this download.
5. Pass the selected home only to the Reseam or build process. On POSIX, use `JAVA_HOME="$java_home" "$reseam" ...` with the CLI's absolute path. On Windows, set `JAVA_HOME` in the child process environment. This keeps Java outside the project and requires only user permissions.
